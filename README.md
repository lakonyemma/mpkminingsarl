# MPK Mining SARL Website

A responsive corporate portfolio website for MPK Mining SARL, a Tanzania-based mineral mining company focused on gold mining, gold processing and gold sales.

## Files
- `index.html`: page structure and company content
- `styles.css`: responsive visual design and layouts
- `script.js`: mobile navigation and current footer year

## Run locally
Open `index.html` in a browser. No build step or package installation is required.
