# MPK Mining SARL Website

A responsive corporate website for MPK Mining SARL, positioned across mining and mineral processing in Tanzania and international gold sales.

## Files
- `index.html`: page structure and company content
- `styles.css`: responsive visual design and layouts
- `script.js`: mobile navigation, seven-language translations, language preference and buyer enquiry email flow

## Run locally
Open `index.html` in a browser. No build step or package installation is required.
